# 当新版 Win11 遇上旧 PE：那个卡在“等待清理完成”的白屏陷阱

---

> 最近给家里的老机器升级固态硬盘并重新安装 Windows 11，本以为是轻车熟路的常规操作，却在刚开局就撞上了一个极其诡异的白屏故障。

按照往常的习惯，进 PE 挂载 ISO 镜像、双击运行 `setup.exe`，前面选语言、选版本都畅通无阻。但只要点击“下一步”，界面刚闪过一行文字提示 **“等待清理完成”**，整个窗口就瞬间变成大片纯白，彻底死锁。

等待半小时依然没有丝毫动静，点击右上角关闭按钮还会弹出安装程序异常退出的报错。在排除了镜像损坏、U盘掉盘和硬件兼容问题后，最终找到了根源与最省心的解法。特此记录这篇排坑笔记，希望能帮到遇到相同情况的朋友。

## 1/4：事发现场：闪过“等待清理完成”后界面全白

---

先还原一下当时的软硬件环境和操作经过：

1. **测试硬件**：一台配置稍老的 Intel 平台电脑（或者老主板平台），准备安装到全新的 NVMe/SATA 固态硬盘上。
2. **PE 工具**：经典的 **微PE工具箱 64位 V2.3**（`WePE_64_V2.3.iso`），这是很多装机爱好者的首选工具，纯净无捆绑。
3. **系统镜像**：Windows 11 官方商业版/消费者版 64位 ISO 镜像（如 `zh-cn_windows_11_business_editions_version_25h2_x64_dvd_22759158.iso` 及 24H2 等较新版本）。

在微PE桌面里，用 DiskGenius 将新硬盘快速分区为 **GUID（GPT）** 格式，并保留了 300MB 的 ESP 引导分区。随后装载 Windows 11 ISO 镜像，双击运行光盘根目录下的 `setup.exe`。

跳过产品密钥输入界面，选择所需的具体版本（例如专业版或专业工作站版），点击右下角的 **“下一步”**。

此时屏幕正中央短暂闪现文字提示 **“等待清理完成”**。紧接着，安装向导窗口内容骤然消失，变成大片空洞的纯白区域。无论是晃动鼠标还是耐心等待半小时，CPU 占用率始终为零，没有任何解压文件的磁盘读写迹象。

强行点击窗口右上角关闭，系统直接抛出程序崩溃的异常错误框。换用了微软官网重新下载的原版镜像，甚至将镜像直接拷贝到本地另一块 SSD 避开 U 盘传输瓶颈，该白屏故障依然 **100% 精确复现**。

## 2/4：溯源根因：新版安装器与精简 PE 的兼容性断层

---

遇到这种情况，第一反应往往会怀疑是内存 XMP 不稳、BIOS 设置未开启 TPM，或者是 ISO 文件下载校验有误。但真正的罪魁祸首，其实是 **微软新版安装向导** 与 **老旧 WinPE 运行环境** 之间的兼容性断层。

从 Windows 11 24H2 及后续版本开始，微软对安装镜像内的安装程序架构进行了大幅重构，引入了基于新版运行时、WebView2 以及现代化 XAML 框架的全新向导界面。

在用户选定系统版本并准备跳转到磁盘分区列表的瞬间，新版向导会触发一系列上下文清理与临时服务重置动作，这便是界面短暂显示 **“等待清理完成”** 的由来。

然而，**微PE V2.3** 的核心基于较早期的 Windows 10 PE 内核精简定制。为了保持轻量无冗余，它裁剪了大量对于系统维护非必需的组件库与现代化渲染依赖。

当新版安装程序尝试调用宿主 PE 并不具备的现代运行时接口时，渲染线程直接抛出未捕获异常导致视口完全留白，安装流程就此卡死。

## 3/4：换个解法：使用微PE自带的 WinNTSetup 部署系统

---

既然知道了是官方图形安装向导 `setup.exe` 的渲染逻辑与 PE 冲突，最干脆利落的破解方案就是：**彻底抛弃 `setup.exe`，直接使用镜像释放工具**。

`setup.exe` 归根结底只是一个前台交互外壳，其实质工作无非是把镜像 `sources` 目录下的系统母包（`install.wim` 或 `install.esd`）释放到目标磁盘，并利用 `bcdboot` 生成 UEFI 启动引导。

微PE桌面和开始菜单中早已内置了老牌神器 **WinNTSetup**，它直接走底层的 DISM / WIM API 释放镜像，完全不需要调用任何容易崩溃的图形向导。具体实操步骤如下：

### 第一步：定位安装镜像母包

在微PE中右键点击 Windows 11 的 ISO 文件，选择“装载为虚拟磁盘”（或者用 7-Zip 直接提取）。装载后记下对应的盘符，母包文件就位于虚拟光驱的 `sources\install.wim`（某些合盘可能是 `install.esd`）。

### 第二步：配置 WinNTSetup 三大核心路径

打开微PE桌面上的 **WinNTSetup**，界面非常直观，重点配置顶部三栏：

1. **选择包含 Windows 安装文件的文件夹**：点击右侧“搜索”，找到虚拟光驱里的 `sources\install.wim`。选中后，可以在下方下拉菜单中直接选择心仪的版本（如 **Windows 11 专业版**）。
2. **选择引导驱动器位置**：点击“搜索”，选择硬盘上的 **ESP（EFI）引导分区**。如果分区正常，旁边的状态指示灯会显示为绿色对勾。
3. **选择安装驱动器位置**：点击“搜索”，选择你要作为系统主盘的常规分区（通常是格式化好的 **C 盘**）。

### 第三步：配置旧电脑优化开关（锦上添花）

如果你的电脑配置较老、主板不支持 TPM 2.0 或未开启安全启动，可以在 WinNTSetup 界面的右下角微调选项中，勾选以下实用功能：

- **破解系统安装限制（Bypass TPM / Secure Boot / RAM 检查）**：完美拯救老机器，无需手动修改注册表 `LabConfig`。
- **创建本地管理员账户**：跳过微软强制联网登录个人 Microsoft 账号的流程。

全部核对无误后，点击右下角的 **“开始安装”**。在弹出的确认窗口中保持默认选项（引导方式选择 UEFI），点击确定，工具便会以极高的读写速度直接将系统映像释放到 C 盘。

## 4/4：拔盘重启：顺利跑通系统初始化与避坑小结

---

当 WinNTSetup 弹出“操作已成功完成”的提示框后，系统文件和启动引导均已妥善就位。

1. **拔出 PE 优盘**：关闭所有软件，拔出插在机箱上的微PE U盘，避免重启时再次自动进入 PE 引导。
2. **重启计算机**：电脑主板自检完成后，会直接移交控制权给硬盘上的 Windows Boot Manager。
3. **进入全新开机向导**：此时你会看到熟悉的 Windows 11 滚圈界面，系统会自动完成驱动整合、服务配置，并顺利进入初次使用的 OOBE 桌面向导。

整个安装过程前后耗时不过五六分钟，彻底绕过了原版 `setup.exe` 在“等待清理完成”时带来的无尽白屏噩梦。

## 善后工作（常见疑惑与排查）

---

这里整理了几个装机过程中容易困惑的常见细节，供遇到瓶颈时对照排查：

- **问：ESP 引导分区在 WinNTSetup 里指示灯显示黄灯或红灯？**
  - **排查**：检查硬盘分区表是否为 GPT 格式，ESP 分区的文件系统必须是 **FAT32**，且建议分配 100MB~300MB 空间。若在资源管理器里看不到该分区，可使用 DiskGenius 为其临时指派一个盘符。
- **问：重启进入系统初始化时提示必须连接网络，没有跳过选项怎么办？**
  - **排查**：如果在 WinNTSetup 里没有勾选离线账户优化，可以在 OOBE 联网界面按下快捷键 `Shift + F10`（部分笔记本为 `Shift + Fn + F10`）调出 CMD 窗口，输入命令 `OOBE\BYPASSNRO` 并回车。系统会自动重启，重启后网络连接页面右下角就会多出“我没有 Internet 连接”的跳过按钮。
- **问：后续日常使用微PE安装其他系统还会有这个情况吗？**
  - **排查**：目前已知该白屏现象主要集中在 Win11 24H2 / 25H2 等采用新版向导架构的镜像中；安装 Windows 10 或较早期的 Windows 11 22H2/23H2 时一般不会出现。只要是在旧版 PE 环境下给新系统装机，优先使用 WinNTSetup 永远是稳定性最高、排坑最彻底的稳妥方案。
