# 告别排版折磨，像写 Markdown 一样写 Steam 指南

在 Steam 社区写过成就攻略、MOD 教程或者流程解密的玩家，多半都领教过官方自带编辑器的难用。

Steam 指南后台用的是古老的 BBCode 格式。官方提供的编辑器不仅预览麻烦，格式还容易在保存后错乱，手写标签更是费时费力。

如果你习惯了 Markdown 所见即所得的节奏，可以用这套简单的浏览器工作流：一边写一边预览，写完直接复制代码粘贴进 Steam 后台。

写这篇指南前，默认你懂基本的 Markdown 语法，且浏览器里已经装好了 Tampermonkey 或 Violentmonkey 这类脚本管理器。

## 1. 安装 Markdown 转 BBCode 油猴脚本

开发者 YellowAfterlife 制作过一个很实用的用户脚本，可以在指定的在线 Markdown 编辑器里增加转码按钮。

1. 打开 [Markdown to BB code 脚本发布页](https://yal.cc/markdown-to-bb-code/)。
2. 点击安装 Userscript 脚本，并允许它在配套的编辑器域名下运行。
3. 在油猴扩展里确认脚本已处于开启状态。

这个脚本做过 Steam BBCode 标签的专门适配，能把标题、粗体、列表和超链接准确映射成 Steam 支持的格式。

## 2. 在线编写与一键复制代码

脚本装好后，打开配套的在线编辑器即可开始写内容：

1. 浏览器打开 [Markdown Editor](https://jbt.github.io/markdown-editor/)。
2. 页面右上角的工具栏会多出一个 **Copy BB code** 按钮。
3. 左侧面板输入 Markdown 内容，右侧会实时显示排版渲染预览。
4. 撰写完毕后点击右上角 **Copy BB code**，转好的富文本代码就会存进剪贴板。
5. 打开 Steam 社区指南编辑页，在章节内容框里直接粘贴（Ctrl+V）并保存。

不需要在本地导出多余的文件，直接在浏览器网页里完成所有编写和转换。

## 3. 复杂表格的处理方式

如果攻略里包含大段数值对照、掉落概率或者装备属性，可能会用到表格。

虽然 Markdown 支持简单的管道符表格语法，但 Steam 的表格语法（`[table]`、`[tr]`、`[th]`、`[td]`）在直接转换时偶尔会出现格式跑偏。

如果遇到复杂表格，建议配合在线表格转换器：

1. 搜索关键词 **bbcode-table-generator** 或使用类似的在线表格制作工具。
2. 把数据填进网格，或者直接从 Excel 复制粘贴进去。
3. 生成兼容 Steam 的表格代码，单独贴进你的指南对应位置。

## 发布前的两点避坑注意

在把内容发到 Steam 之前，有两处系统机制需要提前了解：

### 1. 图片不能直接用外链转换（最关键的一点）
Steam 社区为了安全考量，**禁止在指南里直接引用第三方外链图片**。
- 所有插图必须在 Steam 指南编辑页右侧的“上传图片”面板里，一张一张上传到 Steam 自己的服务器。
- 如果图很多，YellowAfterlife 还做过一个配套的 **Autolink** 脚本，在批量上传到 Steam 后可以自动把 Markdown 的图片占位符对号入座，省去手动填 ID 的麻烦。

### 2. 行内代码与换行差异
- **行内代码**：Markdown 的反引号行内代码在 Steam BBCode 里没有完美的原生对应样式，贴过去容易变成普通文本。
- **换行距离**：Steam 编辑器对空行比较敏感。如果保存后感觉段落太挤或太散，可在编辑器里微调空行数量。
